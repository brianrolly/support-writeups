# Support Writeups

Static GitHub Pages portfolio for Brian Rollinson.

The site contains sanitized case studies covering Linux support, application and infrastructure troubleshooting, change management, and verified remediation. It is intentionally build-free: GitHub Pages can publish the repository root directly.

## Local preview

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080/`.

## Publishing

Configure GitHub Pages to deploy from the `main` branch and repository root.
